# OAIP Battles

Баттл по C++ для групп 678101–678105.

## Файлы

```
teams/teamN/solution.cpp
tests/teamM/0N_описание/input.txt
tests/teamM/0N_описание/expected_output.txt
```

`N` — номер группы от 1 до 5: `team1` — 678101.

### Решения

`teams/teamN/solution.cpp` — один файл с решением группы.

### Тесты

- `tests/teamM/` — группа, которую атакуют.
- `0N_описание/` — группа, которая атакует. `0N` — номер от 1 до 5.
- Внутри теста — `input.txt` и `expected_output.txt`.

Пример: `tests/team1/04_dup_article/` — 678104 атакует 678101.

Свою группу атаковать нельзя.

## Группам

Не добавляйте файлы в репозиторий. Передайте преподавателю:

- решение — файлом `solution.cpp`;
- тесты — папками по правилам именования выше.

## Преподавателю

1. Создайте в GitHub ветку `vs/A-B`, где `A` и `B` — разные номера групп от 1 до 5. Пример: `vs/1-4`.
2. В этой ветке добавьте:
   - `teams/teamA/solution.cpp` и `teams/teamB/solution.cpp`;
   - `tests/teamA/0B_*` — тесты группы B против A;
   - `tests/teamB/0A_*` — тесты группы A против B.
3. Сделайте коммит и пуш. Подождите, пока CI проведёт баттл и запишет результат в `main`.
4. Удалите ветку `vs/A-B` после баттла. В `main` её не переносите: решения и тесты хранятся только в ветке баттла, поэтому перед следующим баттлом репозиторий остаётся чистым.
